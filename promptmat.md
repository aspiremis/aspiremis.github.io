I do NOT want a collection of random notes.

---

# Primary Goal

Design a learning experience that allows someone with **zero prior programming knowledge** to gradually become capable of solving real Power System Engineering problems using MATLAB and Python.

The emphasis should be on **deep conceptual understanding**, not memorizing syntax.

---

# Learning Philosophy

Every topic should follow First Principles.

Never assume prior knowledge.

Every new concept must answer:

- What problem does this solve?
- Why was it invented?
- When should it be used?
- How does it work internally?
- Where is it used in engineering?
- What mistakes do beginners make?
- How does it compare with alternatives?

The content should feel like reading an excellent textbook combined with an interactive course.

---

# Learning Style

Do NOT simply explain syntax.

Every chapter should include:

## 1. Intuition

Simple explanation

Real-world analogy

Visual explanation

Engineering motivation

---

## 2. Theory

Explain the concept deeply.

Avoid skipping steps.

Derive ideas whenever possible.

---

## 3. MATLAB Implementation

Start with the simplest example.

Gradually increase complexity.

Explain every line.

---

## 4. Visualization

## 7. Mini Project

Summarize key takeaways.
